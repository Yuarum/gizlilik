# Privacy Policy for Fluke

This privacy policy applies to the **Fluke** app created by **Abra Interactive** as a Free service. This service is intended for use "AS IS".

## Local Data Storage (Save System)
The Application includes a game save system to preserve your in-game progress, high scores, and settings. 
* **Local Storage:** All save data is stored locally on your own device.
* **No Server Collection:** This data is not transmitted to, stored on, or shared with any external servers or third parties by Abra Interactive.
* **Data Deletion:** You can delete this data at any time by clearing the application data through your device settings or by uninstalling the Application.

## Information Collection and Use
The Application collects information when you download and use it. This information may include:
* Your device's Internet Protocol address (IP address)
* The pages of the Application that you visit, the time and date of your visit
* The operating system you use on your mobile device
